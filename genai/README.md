# FogoCerto · Generative AI for Engineering

Assistente que responde dúvidas sobre uso do fogo no meio rural com base na lei, citando a fonte e recusando o que a base não cobre.

Estrutura pedida pela disciplina:

```
notebooks/   notebooks com as saídas salvas
base/        trechos e fontes (Lei 14.944/2024, Lei 12.651/2012, Lei 9.605/1998)
avaliacao/   casos de teste e placar das 3 configurações
README.md    como reproduzir
```
