# Hardware

## Hardware físico - componentes originais
- ESP32 DevKit V1;
- Driver de motores L298N;
- Dois motores DC;
- Sensor ultrassônico HC-SR04;
- Alimentação original por quatro pilhas AA.

## Sensores ambientais adicionados em implementações virtuais
- Sensor DHT22: leitura de temperatura e umidade;
- Sensor MQ-2: detecção indicativa de fumaça e gases.

## Componentes auxiliares
- Protoboard;
- Jumpers;
- Resistores e divisor de tensão, quando necessários.

## Recursos virtuais - demonstração e simulação
- Mockdata para cenários ambientais;
- Snapshot Gold fictício para testes;
- Cenários simulados de temperatura, umidade e fumaça;
- Modelo de Machine Learning para classificação local do risco.
