# Mockdata

Os cenários demonstrativos são:
- BAIXO: 27 °C, 58% de umidade, sem indicação de fumaça.
- MÉDIO: 32 °C, 38% de umidade, sem indicação de fumaça.
- ALTO: 39 °C, 24% de umidade, indicação de fumaça.

Esses valores são mockdata de demonstração, não observações ambientais reais. No Monitor Serial, `m` alterna os cenários.
